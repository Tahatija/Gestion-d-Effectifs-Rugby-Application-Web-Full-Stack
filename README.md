# Gestion d'Effectifs Rugby — Application Web Full-Stack

## Description
Projet académique de gestion des effectifs d’un club de rugby.  
Cette application Full-Stack permet de gérer les joueurs et leurs informations via des formulaires et un affichage dynamique des données, offrant une expérience simple et structurée pour l'administration d'une équipe.

## Fonctionnalités
- Ajout, modification et suppression des joueurs via formulaires PHP
- Affichage dynamique des effectifs dans des tableaux HTML
- Gestion et stockage des données avec une base PostgreSQL
- Validation des données côté serveur
- Interface simple et intuitive pour l’utilisateur

## Technologies
- PHP (côté serveur)
- PostgreSQL (base de données)
- HTML / CSS (front-end minimal)
- Git pour versioning

## Compétences démontrées
- Conception et gestion d’une base de données relationnelle
- Requêtes SQL (INSERT, SELECT, UPDATE, DELETE)
- Développement Full-Stack simple et structuré
- Organisation de projet et structuration des fichiers
- Travail sur formulaires et affichage dynamique des données
